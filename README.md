Spendly -- Personal Finance & Smart Savings Tracker
Spendly is a personal finance web application that helps users
understand and manage their money in one place.
Features
- Income and Expense Tracking: Add and manage daily income and
  expenses.
- Dashboard: View total income, total expenses, remaining balance,
  and savings rate.
- Charts: Understand spending patterns through visual charts.
- Monthly Budgets: Set spending limits for different categories
  and receive alerts when approaching or exceeding a limit.
- Savings Goals: Set savings targets and track progress as you
  contribute money.
- Smart Insights: Get rule-based tips based on spending and
  savings activity.
- Secure Login: Create an account and sign in securely.
Tech Stack
- React: Builds the interactive user interface.
- Vite: Runs and builds the React application.
- Java: Main programming language for the application logic.
- Spring Boot: Provides the application's backend services and
  APIs.
- Spring Security and JWT: Handle authentication and protected
  access.
- SQLite: Stores user accounts, transactions, budgets, and savings
  data.
- Recharts: Displays financial data as charts.
- Axios: Connects the user interface to the application APIs.
How It Works
1. Create an account or log in to access your personal dashboard.
2. Add income and expenses with an amount, category, and date.
3. Review your dashboard to understand your income, spending, and
   remaining balance.
4. Create monthly budgets to monitor spending in different
   categories.
5. Set savings goals and record contributions to track progress.
6. View smart insights and charts to identify spending patterns and
   make more informed budgeting decisions.
Each user's financial records should be accessible only to that
authenticated user.
